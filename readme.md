Agrova 🌱
Crop Recovery & Settlement Platform
Built by Team INNOVATRIX
Live Url: https://agrova-innovatrix-1.onrender.com/
Agrova is a prototype designed to help Farmer Producer Organisations (FPOs) manage crop quality mismatches, find suitable buyers, and track produce from an order shortage to a transparent settlement.
Version 1 — Basic Frontend
This initial reconstructed V1 baseline includes:
- A responsive dashboard for an FPO collection centre
- Farmer lots, quantities, grades, and safety status
- Buyer requirements and basic crop matching
- Shortage calculations and alternative buyer suggestions
- Demo data saved in the browser
Note: V1 is a reconstructed starting point based on the project concept, not the original historical V1 source. Buyer data is illustrative.
Tech Stack
- HTML, CSS, JavaScript
- Node.js (local development server)
- Browser localStorage (demo data)
Run Locally
1. Install Node.js 18 or newer.
2. Open this project folder in VS Code.
3. Open a terminal and run:
npm start
4. Visit http://localhost:3000.
To run tests:
npm test
No API key or database setup is required for V1.
Development Roadmap
- V1: Basic frontend and buyer-matching demo
- V2: Recovery reservations, delivery evidence, and settlement review
- V3: Shortage fulfillment, net recovery comparison, quality passport, and farmer ledger
